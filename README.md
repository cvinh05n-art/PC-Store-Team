# ✨ Giới thiệu

**PC Store Team** là một website thương mại điện tử chuyên cung cấp:

- 🧩 CPU
- 🎮 GPU
- 💾 RAM
- 💿 SSD
- 🖥️ Mainboard
- 🔌 Nguồn máy tính
- 🧊 Tản nhiệt
- ⌨️ Phụ kiện máy tính
